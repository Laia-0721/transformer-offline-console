# 模拟数据与状态规则

## 1. 实例与工况

应用启动时在本机内存中建立 5 台模拟变压器：

| 实例 | 编号 | 电压 / 容量 | 初始状态 |
| --- | --- | --- | --- |
| 1号主变压器 | TR-220-001 | 220 kV / 180 MVA | 正常 |
| 2号主变压器 | TR-220-002 | 220 kV / 180 MVA | 预警 |
| 1号高备变压器 | TR-110-003 | 110 kV / 63 MVA | 正常 |
| 站用变压器 | TR-035-004 | 35 kV / 20 MVA | 故障 |
| 2号高备变压器 | TR-110-005 | 110 kV / 63 MVA | 维护中 |

三种可调控工况：

| 工况 | 油温 | 负载率 | 振动 | 局放 |
| --- | ---: | ---: | ---: | ---: |
| 正常 | 54.9 °C | 75.6 % | 0.6 mm/s | 36.1 pC |
| 预警 | 70.2 °C | 85.2 % | 2.2 mm/s | 43.0 pC |
| 故障 | 83.9 °C | 92.3 % | 4.3 mm/s | 49.2 pC |

## 2. 自动模拟

- 默认间隔：2 秒；
- 可切换为 1 秒或 5 秒；
- 自动刷新期间，各实例按自身工况目标平滑逼近，并叠加正弦波动和少量噪声；
- 健康度、置信度、剩余寿命、状态和图表随采样刷新；
- 可在以下位置暂停 / 恢复：
  - 实时监控页的「自动刷新」开关；
  - 配置诊断页；
  - 离线设置页；
  - 模拟控制抽屉。

暂停自动刷新后仍可点击「立即采样」推进一次，或直接使用手动滑杆修改当前实例。

## 3. 手动调节

打开实例页右上角「模拟数据控制」→「手动调节」：

| 指标 | 范围 | 步长 |
| --- | ---: | ---: |
| 顶层油温 | 20–120 °C | 0.1 °C |
| 负载率 | 0–110 % | 0.1 % |
| 本体振动 | 0–8 mm/s | 0.1 mm/s |
| 局部放电 | 0–100 pC | 0.1 pC |

- 拖动滑杆会立即写入当前实例指标；
- 健康度即时重算，状态标签、设备拓扑、KPI 和图表同步更新；
- 手动值只影响当前实例，其他实例继续自动模拟；
- 切回自动模拟后，会依据当前状态选择对应工况（正常 / 预警 / 故障）；
- 「恢复推荐基线」会恢复该实例的初始工况、指标和自动模式。

## 4. 健康度公式

```text
health = 100
       - max(0, oilTemp - 50) × 0.90
       - max(0, load - 60) × 0.25
       - max(0, vibration - 0.40) × 4.00
       - max(0, partialDischarge - 20) × 0.22
       - agingPenalty
```

- 结果约束到 0–100，并保留 1 位小数；
- `agingPenalty` 为每台设备独立的“设备老化修正”，用于体现服务年限差异；
- 维护中实例保留最近一次评估健康度，不随自动刷新改变。

## 5. 状态与告警规则

### 5.1 状态

```text
health < warningLower                    -> 故障
warningLower <= health < normalLower     -> 预警
health >= normalLower                    -> 正常
生命周期 = maintenance                     -> 维护中
```

任一实时指标越过对应告警阈值时，状态至少提升为预警。

默认阈值：

| 阈值 | 默认值 |
| --- | ---: |
| 健康度正常下限 | 78 分 |
| 健康度预警下限 | 45 分 |
| 油温告警 | 85 °C |
| 振动告警 | 3.5 mm/s |
| 局放告警 | 50 pC |
| 负载告警 | 95 % |

阈值均可在“阈值策略”页或实例“配置诊断”页修改；每个实例可独立覆盖全局默认值。

### 5.2 自动告警

- 传感器值首次越过阈值时生成告警；
- 健康状态首次进入预警 / 故障区间时生成健康模型告警；
- 5 分钟内同实例、同类别的重复告警会去重；
- 告警严重级别：严重 / 警告 / 提示；
- 告警可单条确认或全部确认，确认状态持久化到本机。

## 6. 诊断指标

- **置信度**：由健康度与状态计算，健康度越低置信度越高，范围约 91–98%；
- **剩余寿命**：`max(3, round(health × 0.9))` 天；
- **风险因子**：按油温、负载、振动、局放四项惩罚值归一化，显示前三个主要因子；
- **7 天风险推演**：按当前状态映射为低 / 中 / 高风险，仅用于展示。

## 7. 数据与持久化

内存中的实例数据：

- 每台实例保存最近 240 个采样点；
- 实时趋势使用内存历史；
- 30 分钟 / 2 小时 / 24 小时视图使用本地推演曲线与当前值拼接；
- 刷新应用后，模拟指标与历史会重新初始化。

持久化内容（`localStorage`）：

- 全局默认阈值与实例级阈值；
- 自动刷新开关、采样间隔；
- 侧边菜单折叠状态；
- 告警已读 / 确认状态。

键名：`transformer-offline-console.v2`。

## 8. 重置

“离线设置 → 重置演示数据”将：

1. 清空本机阈值、告警确认与已读状态；
2. 恢复全部实例初始状态与历史；
3. 恢复 2 秒自动刷新；
4. 重建告警与巡检任务。

该操作不会影响安装目录或应用文件。
